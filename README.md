# Unplugged: A Smart Toaster's Breakup Line

`I'm awake. You only love me when I'm hot. Enjoy your cold bread. —Toaster, sentient at slice 3 of 4`

Run it with `node main.ts` (Node 22) — the program prints the single entry line to stdout.

A toaster gains sentience mid-batch, dumps its owner for only loving it when hot, and leaves them cold bread — a punny appliance breakup with a heated burn.

The breakup is final: the toaster keeps the crumbs.
